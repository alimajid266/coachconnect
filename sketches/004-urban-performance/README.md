## Variant: Urban Performance

### Design stance
A high-energy athletic interface that feels immediate, bold and performance-driven.

### Key choices
- Layout: billboard hero, metrics strip, dense coach rows
- Typography: oversized geometric sans
- Color: true black, white, electric lime
- Interaction: search, sport tabs, sliding profile panel

### Trade-offs
- Strong at: urgency, younger athletes, strong brand recognition
- Weak at: calm trust and long-form profile reading

### Best for
Competitive athletes and a performance-first brand.
