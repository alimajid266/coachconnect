## Variant: Friendly Marketplace

### Design stance
A warm, approachable discovery product with search and map always in view.

### Key choices
- Layout: centered search hero, card grid, sticky map
- Typography: friendly rounded sans-serif
- Color: warm white, coral, sage
- Interaction: search, sport chips, profile feedback

### Trade-offs
- Strong at: usability, broad audiences, marketplace clarity
- Weak at: distinctive premium or performance edge

### Best for
CoachConnect's current MVP and mixed family/athlete audience.
